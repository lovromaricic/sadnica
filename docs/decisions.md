# Decisions

Spec gaps and the simplest choice made for each. Review and overrule freely.

## Platform

- **SvelteKit 3 / Svelte 5 / Vite 8.** These were the current versions at scaffold time. Kit 3 differences
  from older guides: config lives in `vite.config.ts` (`sveltekit({...})`), `$lib` is replaced by the
  `#lib/*` subpath import (needs a file extension, e.g. `#lib/season.ts`), `$app/env` replaces
  `$app/environment`, and the service worker lives in `src/service-worker/` and reads `$app/manifest`.
- **Pages render in the browser** (`ssr = false`, `prerender = true`). Every screen depends on
  localStorage and today's date, so server-rendered HTML would be wrong for most visitors. Each route,
  including every plant page, is still prerendered as an HTML shell, so the site is plain static files
  and every URL works on a static host and offline.
- **`trailingSlash = 'never'`**: output is `biljke.html`, `biljke/cesnjak.html`. Most static hosts serve
  these for `/biljke` and `/biljke/cesnjak`.
- **Fonts** come from Google Fonts as specified. The service worker caches them on first visit so they
  work offline afterwards. The stylesheet is preloaded and applied on load instead of blocking first
  paint (see docs/audit.md).
- **Content is validated at build time only.** `npm run validate` (part of `npm run build`) checks the
  JSON against the zod schemas; the app imports it as-is so zod stays out of the client bundle.
- **Icons** are generated by `scripts/make-icons.mjs` (no dependencies) from the same sprout as the logo.

## Season logic (`src/lib/season.ts`)

- Windows are whole months, inclusive, and may wrap the new year (`{ from: 11, to: 2 }`).
- `late` ("Još stigneš"): within `rules.lateDays` (21) days of the window's last day, **or** the window
  has `needsCover`.
- `upcoming`: the next window starts within `rules.upcomingMonths` (5) months. Further away is `off`.
  In October this makes tomato (February), carrot and basil (March) "Uskoro", as in the design.
- In the catalogue, `upcoming` and `off` both show the grey "Nije sezona" chip; the timing line says
  when it starts ("od veljače").
- If two windows overlap, the one without `needsCover` wins.
- **Recommendation order**: plants that need cover go last; then easy before medium before hard; then
  the window that closes soonest; then the optional
  per-plant `rank` field; then name. `rank` was added because several plants share the same window
  end (garlic, shallot and onion sets all close at the end of November) and the design leads with garlic.
- **Frost alert** shows from `frostAlertDays` (21) days before the typical first frost until the end of
  the frost window in `data/rules.json`. Coastal frost is set to December to mid January.
- "samo uz pokrov" replaces the timing line for `needsCover` plants while frost is near.

## Content and data

- Added optional plant fields: `nameAccusative` (task and headline grammar: "Posadi rajčicu",
  "Ovaj tjedan sadimo luk ljutiku"), `rank` (see above), and `spacingTip` (the "Dobro je znati" line of
  the Razmak modal).
- The hero reason on Danas is generated: "Posadi do kraja studenog, berba od lipnja do srpnja." plus
  "Jedna od najlakših biljaka za početak." for easy plants.
- **All gardening text is placeholder** and every content file has `"reviewed": false`. The build
  prints a reminder while any are unreviewed.
- Neighbour names that match a catalogue plant link to that plant.

## Location

- `src/lib/cities.ts` has ~40 Croatian towns with region and locative ("u Zagrebu"). Unknown towns
  fall back to continental and the heading becomes "Kada, za mjesto X".
- The region switch (Kontinentalno / Primorsko) sits under the city field on the onboarding screen,
  which is the "settings" screen too: the location pill in the desktop header opens it. Picking a
  region by hand overrides the city lookup.

## Balcony (place answer)

The question has three answers: "U vrtu ili gredici" (`garden`), "Na balkonu ili u loncima"
(`balcony`) and "Još ne znam" (`unsure`). It used to have four; ground and raised bed gave identical
advice, so they were merged. Saved answers carry over (ground and raised → garden, none → unsure).
Only the balcony answer changes anything; the others keep the default behaviour. Pots are where a
beginner most often plants something that cannot work, so that case earns the question.

- **Data**: optional per-plant `containers: { ok, minPotCm?, note? }`. `minPotCm` (smallest pot
  diameter) is required when `ok` is true and not allowed when false; `npm run validate` enforces this
  and lists plants with no `containers` at all. A plant without the field counts as not for pots
  (it is never preselected or made the hero), but the plant page shows no "Nije za lonac" note for it,
  since we simply do not know. Pot sizes and notes are placeholders like the rest of the content.
- **Danas**: pot-friendly plants rank first, ahead of the usual order (so with balcony, a cover-only
  pot plant beats a cover-free one that needs a bed). The hero is the first pick only if it suits a
  pot; otherwise there is no hero and the text says nothing fits a pot now, and the other plants stay
  in the list below. "Vidi sve u sezoni" counts and opens in-season pot plants (`?filtri=season,balcony`).
  (Broad bean, the original example of a non-pot plant here, is now sown inland only in spring.)
- **Plant page**: for a pot-friendly plant the Razmak tile becomes "Lonac · Ø 20 cm" and its modal says
  "Treba ti lonac promjera barem 20 cm." plus the plant's note, with a generic drainage tip. For a plant
  marked `ok: false`, a short peach note sits above the tiles ("Nije za lonac." + the plant's note).
- **Catalogue**: new "Za balkon" filter (AND with the others), second in the row so it is visible on a 393px phone when preselected. Balcony gardeners get it switched on
  when they open Biljke without filters in the address. If they switch everything off, the address
  keeps an empty `?filtri=` so Back to the catalogue does not switch it on again.

## Moj vrt

- Stages: Za posaditi → Posijano → Raste → Spremno za berbu. A button on each card moves to the next
  stage. Progress bar: 8% / 35% / 68% / 100%.
- Weekly tasks are generated from garden + date: plant (in season), cover (frost near and the plant
  has a cover window), harvest (stage ready, or growing in a harvest month), check water (thirsty
  plants, May to September). Tick marks are stored per ISO week, so the list resets every Monday.
- Ticking "Posadi X" also moves X to Posijano (unticking moves it back); the ticked task stays visible
  for the rest of the week.
- **Stage dates**: each garden plant keeps the day it reached each stage (`stageDates`, local
  YYYY-MM-DD). Moving forward stamps today, undoing a stage forgets its date. Plants saved before this
  get their "Dodano" day from `addedAt`; later stages stay undated until the user sets them.
- The card and plant page show the current stage's day ("Posijano 19. listopada") and, while sown or
  growing, "Berba oko <month>": the first harvest month after the sowing month, up to a year ahead,
  with "iduće godine" when it falls next year. Month precision only, like the rest of the calendar.
- Dates are corrected on the plant page ("Promijeni datum"). A day cannot be in the future or before
  the previous growing stage; the "Dodano" day does not limit the sowing day, since a plant can be
  added after it was sown.
- Step check marks on a plant page are saved with the plant when it is in Moj vrt, otherwise they
  last for the visit only.

## Smaller choices

- **No experience question** (removed after review): it only reordered Danas and, with the current
  plants, changed nothing visible. Everyone gets the beginner order (easy first). Onboarding is now city
  and place; old saves simply drop the stored answer.

- **Changing your answers** (location pill → onboarding screen): no bottom nav there; instead an
  "Odustani" button leaves without saving (Back to the previous page, or Danas after a fresh load), and
  the final button reads "Spremi promjene". First-run onboarding is unchanged.

- **Phone header**: Danas, Biljke and Moj vrt start with the logo and the location pill (which opens
  the location screen), since phones have no top header. It scrolls away with the content; plant
  pages and the sun check keep their own top bars.

- **Tabs and plant pages**: a plant page belongs to the tab it was opened from (Moj vrt, Danas or
  Biljke; a fresh load or shared link counts as Biljke). That tab stays highlighted, and the back arrow
  returns to it: a real browser Back when the tab was the previous page (keeps scroll), otherwise a
  link to the tab's last address. Plant-to-plant neighbour links keep the original tab.
- The catalogue keeps search and filters in the address (`?q=luk&filtri=veg,easy`) so Back restores
  them. The old `?sezona=1` link still works.
- The plant page badge shows the garden stage ("U vrtu · Raste") once a garden plant is past
  "Za posaditi"; before that, and for plants not in the garden, it shows the planting season.

- **Mobile nav labels** are always visible (requested after review), stacked under the icons so the
  floating pill still fits a 360px screen; the active item keeps the lime highlight. This differs from
  the design, where only the active item shows its label.

- Confirmation after adding a plant: a toast with "Otvori moj vrt", 6 seconds.
- Offline notice: a small butter-coloured bar when the browser reports no network.
- Reminder: an `.ics` all-day event spanning the rest of the current window (or the next window),
  with a 9:00 alarm on its first day.
- Mobile onboarding shows the big intro only on the first step; later steps show a compact header.
- When onboarding is reopened from the header, the intro panel drops its logo (the header has one).
- **Testing other dates:** add `?datum=2027-03-15` to any URL. It sticks for the browser session;
  `?datum=` clears it.

## Sun check (`/sunce`)

- **Design boards** (`SunceUlaz` … `DanasDesktopSunce`) were not available to me, so the screens follow
  the spec text and the existing Bento tokens. Expect a visual review pass against the canvas.
- One route, `/sunce?plant=<id>`, with the steps as screens inside it. No plant in the link shows a
  picker (garden plants first). The mobile nav is hidden on this route; it has its own back button.
- **Permissions** are all requested from the "Počni" tap (iOS only allows the motion prompt from a
  tap): motion → location (non-blocking) → camera → wait up to 2 s for a compass reading. Any refusal or
  missing piece goes to the manual screen with a one-line reason. Desktop (no coarse pointer) and
  plain http go straight to manual. Offline needs no special case: suncalc runs locally and the city
  from onboarding replaces geolocation.
- **Location** is used only in memory for the sun path. Fallback: the onboarding city's approximate
  coordinates (`src/lib/cities.ts`), else Zagreb or Split by region.
- **Hours** are whole hours 08–16 local time. An hour with the sun below the horizon counts as not
  sunny and cannot be toggled. Sunny hours = above the horizon and not tapped as blocked.
- **Projection**: pinhole model, 64° vertical field of view for a portrait phone, roll ignored. Heading
  comes from `webkitCompassHeading` on iOS and from `deviceorientationabsolute` on Android. The hour
  chips under the camera toggle the same hours, so the check still works when the compass is off or
  the dots are hard to hit.
- **Manual answers** map to assumed sunny hours so the result can draw the same hour bar:
  Cijeli dan 08–16, Samo ujutro 08–11, Samo popodne 13–16, Skoro nikad 12 only.
- **Verdict copy** is generated from new per-plant `forms` (`nom`, `gen`, `acc`, `plural`), which
  replace `nameAccusative`. `plural` handles agreement ("jagode vole" / "češnjak voli"). No per-plant
  `sunVerdict` strings were needed.
- "Što ovdje uspijeva bolje" lists up to 3 plants whose sun need equals the measured level, then ones
  needing less; with the current 8 seed plants that is often fewer than 3, and none for full shade.
- **QR code** (desktop only): on the desktop manual screen of the sun check (no longer in the Danas widget, to keep Danas light)
  (opens `/sunce?plant=<id>`). It encodes the address the desktop is using, so in development open
  the desktop page via the Network address (`npm run dev:phone`), not `localhost`, or the phone
  cannot reach it. The encoder (`qrcode-generator`, no dependencies) loads only when a code is shown.
- Not built: the design-review "show other outcome" toggle (as instructed).

## Postavke, transfer and backup

- **Postavke** (`/postavke`, gear icon next to the location pill on desktop and on the phone header):
  your answers (changed via the onboarding screen), transfer and backup, delete all data (two-step
  confirm, then onboarding), and an about section. Moj vrt links to the transfer section.
- **Transfer link**: `/uvoz#g=<data>`. The garden (plants, stages, dates, ticked steps) and answers
  are JSON, compressed with the browser's `CompressionStream` (`z` prefix; plain `j` fallback) and
  base64url-encoded after `#`, which browsers never send to a server. A garden of 4 plants is about
  260 characters, comfortably inside a QR code. Desktop shows a QR code and "Kopiraj poveznicu";
  phones get the share sheet (`navigator.share`, falling back to copying).
- **Backup file**: `sadnica-vrt-YYYY-MM-DD.json` with an `app: "sadnica"` tag; anything else is refused.
- **Import** validates through the same sanitiser as local storage and drops plants this version does
  not know. Merge (default): the same plant on both sides keeps whichever is further along; new plants
  are added. Replace: takes the incoming garden and answers, clears this week's ticks. A device that was
  never set up takes the incoming answers and skips onboarding (`/uvoz` is exempt from the
  first-run redirect).
- It is a one-time copy, not sync.

## Companion check

- Neighbour names in the plant data are matched to catalogue plants by name or alias (normalised).
  Bad neighbours count both ways: if either plant lists the other, they conflict. Good neighbours
  count unless the pair is also bad.
- Shown when adding (the toast adds "Ne sadi uz: …"), on the plant page (a warning card in "Susjedi
  u gredici", a note about good neighbours, and an "u vrtu" tag on neighbour pills that are in the
  garden; this works before the plant is added, for planning), and on Moj vrt cards ("Ne uz: …").
- All three add buttons go through one `addToGarden()` so they warn the same way.

## Garden calendar

- Moj vrt shows "Kalendar vrta": one row per garden plant, the next 12 months starting with the
  current one (forward-looking rather than January to December), sowing (S) and harvest (B) months
  for the user's region. Phones put the plant name above its months; desktop puts it on the left.
- It is a real table restyled as a grid, so explicit table roles keep it readable for screen readers.

## Notes and harvest log

- Each garden plant has a `log` of entries (`id`, `day`, `text` up to 500 characters, `harvest`),
  kept in date order. Written and deleted on the plant page ("Bilješke i berba"); Moj vrt cards show
  "Ubrano N×". The log travels with transfers and backups like the rest of the garden.
- Removing a plant that has notes asks first, since the notes go with it.
- Long notes can outgrow a QR code. The QR now uses the low error-correction level (most capacity)
  and, if it still does not fit, Postavke says so and points to sharing the link or a backup file.

## Common problems ("Što nije u redu?")

- Optional per-plant `problems: [{ title, signs, fix }]` in the plant data, three per seed plant,
  validated by the schema and marked unreviewed with the rest of the content. Shown on the plant page
  as native `<details>` rows (keyboard and screen-reader friendly without extra code).
- Not searchable from the catalogue yet; matching problem titles in search was left out to keep
  plant search predictable.

## Frost forecast

- Added after review (the original spec left weather out). Open-Meteo, free and keyless: daily minimum
  temperatures for 7 days at the onboarding town's coordinates rounded to 0.1° (never the phone's own
  location). Cached on the device (`sadnica:prognoza`): fresh for 3 hours, usable for 24 hours, for the
  same place only. Offline or on errors the cache is used, else the typical dates.
- Coming nights are tomorrow up to 6 days ahead (this morning is past). ≤ 0 °C is frost, ≤ 2 °C a cold
  night ("moguć prizemni mraz"); the first such night is reported ("U noći na četvrtak do −2 °C").
- Danas shows the forecast alert first (frost in a darker, urgent style). Without forecast frost, the
  typical-date heads-up remains, prefixed with "Idućih 7 dana nema mraza" when a forecast is known.
- "Frost soon" for tasks and "samo uz pokrov" = forecast frost or the typical period.
- Postavke has a "Prognoza mraza" switch (on by default) explaining what is sent; the about text says
  so too.

## Bigger catalogue (85 plants)

- 42 vegetables, 13 herbs, 20 fruits, 10 flowers. Generated content, every file `reviewed: false`.
  Sowing/planting and harvest windows are given for both regions; asparagus, artichoke, bay laurel,
  berry bushes and fruit trees are `perennial` with years to first harvest.
- **Perennials**: never the Danas hero (also `rank: 300` for trees), "Posađeno" instead of
  "Posijano", "Prvi plodovi za oko N godine" instead of a harvest month, and no harvest task until
  marked ready. Citrus and olive are pot-only on the continent.
- **Flowers** use their `harvest` windows as flowering months: the calendars show "C – Cvatnja", a
  ready flower is "U cvatu", there are no harvest tasks, and Danas says "cvate od … do …".
- Twelve new illustration shapes (pepper, cucumber, pumpkin, cabbage, berry, strawberry, fruit,
  flower, sprig, corn, tuber, stalk) in the same style; colours are per plant.
- **Recommendation order** gained a rule: plants in their prime rank before "Još stigneš" ones.
  With a big catalogue, the plant closing soonest (rocket in October) otherwise became the hero.
- All plant data still ships in one chunk (about 39 KB gzipped). Load per page if it grows a lot.
- Vitest's persistent module cache (`fsModuleCache`) is off: it served a stale plant list to tests
  after new data files were added.

## Broad bean inland

- The design's October sample listed broad bean as "ideal now" in Zagreb. After content review it is
  sown inland in February to April only (autumn-sown plants often die in inland winters); the coast
  keeps autumn sowing. In October in Zagreb it now shows under "Uskoro" (veljača).
- Recommendations rank trees and bushes after all annual plants, so "I još ovo stigneš" suggests
  quick crops (it had started listing a quince tree); they still appear in "Vidi sve u sezoni".

## Pets

- Optional `pets` per plant, after the ASPCA toxic plant list: either `{ safe: true }` (listed as
  non-toxic) or `{ dogs, cats, severity: mild | serious, part, signs }`. 28 plants carry a risk
  (onion family, grapes and daffodil are serious), 15 are marked safe, the rest are unchecked.
- Plant page: a quiet text link under the Latin name (red paw, underlined "Otrovno za pse i mačke", or the softer "Može naškoditi
  psima i mačkama" for mild risks) opening a popup with the dangerous parts, the signs of poisoning,
  "contact a vet" advice and the source. Safe and unchecked plants show nothing.
- The popup has a red header (#b42318) with white text for every risk, mild or serious.
- Catalogue: "Sigurno za ljubimce" shows only plants marked safe, never unchecked ones, because a
  wrong "safe" is worse than no label.

## Planting diagrams (Razmak)

- The Razmak tile opens "Razmak i dubina": tabs Odozgo / Sa strane, a looping 10 s SVG animation,
  one paragraph per view and the tip. Design boards R3–R7 (RazmakKombo, Mrkva, Presadnica, Rasuto,
  Sadnica) give the five templates: clove, row-seed, transplant, broadcast, sapling.
- Data: optional `planting` per plant (lengths in cm, `reviewed: false`), validated per method by
  zod; the build also fails when the first spacing disagrees with `spacingText` or a `tipKey` is
  unknown. 78 of 85 plants have a diagram; hill crops (squashes, melons) and potato and asparagus
  keep the text explanation. So do balcony users, who see the pot size instead.
- Geometry lives in `src/lib/planting/geometry.ts` (pure, tested): each view picks its own scale
  from the numbers so it fits the viewBox. Animation is plain CSS keyframes: every element runs the
  whole loop with its own start offset (no animation-delay, which would drift). Scattered seeds use a
  seeded random generator, so they do not jump between renders.
- Reduced motion shows the finished picture with every label; soil covers stay see-through there so
  the seed or root under them is still visible.
- Row seeding knows the sowing distance (`sowCm`, default a third of the final spacing), so peas and
  beans, which are not thinned, keep every seed with the same code path.
- After a fact check the data gained cases the first design did not have: `tipShowing` (onion
  sets), `surface` (chamomile), `depthMode: dibber` (leek, hole left open), sapling `form` (tree,
  bush, cane) and `support` (pergola, wires). The schema requires a depth exactly when the picture
  shows one; without one the header reads "Razmak" with the spacing only.
- Spacing labels of 100 cm or more are written in metres ("1,5 m") on the tile too, to match.
- Texts avoid gender agreement on the plant where possible ("Presadnicu zakopaj…"); clove texts
  have a "zubac" and a "lukovica" variant; tree texts say "Voćke" for fruit and "Sadnice" otherwise.

## Launch screen

- iPhone: one PNG launch screen per screen size in `static/splash/` (lime background, round sprout
  icon, "Sadnica"), linked with `apple-touch-startup-image` in `src/app.html`. They are rendered in
  local Chrome with the app's font by `npm run splash`. They are left out of the offline cache,
  because iOS reads them only when the app is added to the home screen.
- Android builds its own splash from the manifest; its `background_color` is the same lime.

## Location from GPS

- The place question has "Koristi moju lokaciju": one low-accuracy position on request, matched to
  the nearest of the 41 known cities, which sets the region and the forecast location. The position
  itself is neither stored nor sent; only the city is saved, as when typed by hand.
- Farther than 25 km from every known city, the nearest one is still used and the note says how far
  it is. A finer forecast for remote places (rounded own coordinates) is left for later.

## Hosting in a subfolder

- `npm run build:hosting` builds for `/labs/sadnica/` (`BASE_PATH`); `npm run build` and the dev server
  stay at the root. Pages use relative asset paths; `404.html` (the fallback shell for unknown
  addresses) uses absolute `/sadnica/` paths, so it works at any depth.
- Apache: `static/.htaccess` maps `/biljke` to `biljke.html` and sends unknown addresses to
  `404.html`, where the app shows its own "Ova stranica ne postoji" page. `static/biljke/.htaccess`
  turns off Apache's slash redirect there, because `/biljke` is both a page and a folder. Tested with
  a local Apache 2.4 under `/labs/sadnica/`, below a copy of the `/labs/.htaccess` from the host (its `ErrorDocument 404 /labs/index.html` is harmless while the app's own rules are in place).

## Garden weather

- The same Open-Meteo request now also returns the daily high, rain (mm and chance), wind gusts,
  cloud cover and hourly soil temperature at 6 cm (averaged per day). Cache key `sadnica:prognoza2`.
- Danas shows one card, in this order: forecast frost or a cold night; then `gardenAdvice`
  (`src/lib/gardenWeather.ts`): gusts of 60 km/h or more, 30 °C or more (both within 3 days), rain of
  5 mm or more today or tomorrow, five warm dry days, soil under 10 °C in spring, a mild overcast calm
  day for planting out (March to October, not for balconies); then the typical frost-date reminder.
- The card shows the most important item; when there are more, "Vidi sve savjete (n)" opens a sheet
  with all of them in the same order (forecast frost, `allAdvice`, typical frost reminder) and the
  next 7 days (sky, high and low, rain). No planting-day tip in a week of storms or heat.
- Balcony users get pot versions of the rain and dry-spell advice. Wording stays modest
  ("najavljena je", "očekuje se"). Thresholds are round and cautious; worth a check by a gardener.
