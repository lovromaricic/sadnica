# Decisions

Spec gaps and the simplest choice made for each. Review and overrule freely.

## Platform

- **SvelteKit 3 / Svelte 5 / Vite 8.** These were the current versions at scaffold time. Kit 3 differences
  from older guides: config lives in `vite.config.ts` (`sveltekit({...})`), `$lib` is replaced by the
  `#lib/*` subpath import (needs a file extension, e.g. `#lib/season.ts`), `$app/env` replaces
  `$app/environment`, and the service worker lives in `src/service-worker/` and reads `$app/manifest`.
- **Pages render in the browser** (`ssr = false`, `prerender = true`). Every screen depends on
  localStorage and today's date, so server-rendered HTML would be wrong for most visitors. Each route,
  including every plant page, is still prerendered as an HTML shell, so the site is plain static files
  and every URL works on a static host and offline.
- **`trailingSlash = 'never'`**: output is `biljke.html`, `biljke/cesnjak.html`. Most static hosts serve
  these for `/biljke` and `/biljke/cesnjak`.
- **Fonts** come from Google Fonts as specified. The service worker caches them on first visit so they
  work offline afterwards. The stylesheet is preloaded and applied on load instead of blocking first
  paint (see docs/audit.md).
- **Content is validated at build time only.** `npm run validate` (part of `npm run build`) checks the
  JSON against the zod schemas; the app imports it as-is so zod stays out of the client bundle.
- **Icons** are generated by `scripts/make-icons.mjs` (no dependencies) from the same sprout as the logo.

## Season logic (`src/lib/season.ts`)

- Windows are whole months, inclusive, and may wrap the new year (`{ from: 11, to: 2 }`).
- `late` ("Još stigneš"): within `rules.lateDays` (21) days of the window's last day, **or** the window
  has `needsCover`.
- `upcoming`: the next window starts within `rules.upcomingMonths` (5) months. Further away is `off`.
  In October this makes tomato (February), carrot and basil (March) "Uskoro", as in the design.
- In the catalogue, `upcoming` and `off` both show the grey "Nije sezona" chip; the timing line says
  when it starts ("od veljače").
- If two windows overlap, the one without `needsCover` wins.
- **Recommendation order**: plants that need cover go last; then easy before medium before hard (only
  for "Nikad nisam sadio" / "Malo sam probao"); then the window that closes soonest; then the optional
  per-plant `rank` field; then name. `rank` was added because several plants share the same window
  end (garlic, shallot and broad bean all close at the end of November) and the design leads with garlic.
- **Frost alert** shows from `frostAlertDays` (21) days before the typical first frost until the end of
  the frost window in `data/rules.json`. Coastal frost is set to December to mid January.
- "samo uz pokrov" replaces the timing line for `needsCover` plants while frost is near.

## Content and data

- Added optional plant fields: `nameAccusative` (task and headline grammar: "Posadi rajčicu",
  "Ovaj tjedan sadimo luk ljutiku"), `rank` (see above), and `spacingTip` (the "Dobro je znati" line of
  the Razmak modal).
- The hero reason on Danas is generated: "Posadi do kraja studenog, berba od lipnja do srpnja." plus
  "Jedna od najlakših biljaka za početak." for easy plants.
- **All gardening text is placeholder** and every content file has `"reviewed": false`. The build
  prints a reminder while any are unreviewed.
- Neighbour names that match a catalogue plant link to that plant.

## Location

- `src/lib/cities.ts` has ~40 Croatian towns with region and locative ("u Zagrebu"). Unknown towns
  fall back to continental and the heading becomes "Kada, za mjesto X".
- The region switch (Kontinentalno / Primorsko) sits under the city field on the onboarding screen,
  which is the "settings" screen too: the location pill in the desktop header opens it. Picking a
  region by hand overrides the city lookup.

## Moj vrt

- Stages: Za posaditi → Posijano → Raste → Spremno za berbu. A button on each card moves to the next
  stage. Progress bar: 8% / 35% / 68% / 100%.
- Weekly tasks are generated from garden + date: plant (in season), cover (frost near and the plant
  has a cover window), harvest (stage ready, or growing in a harvest month), check water (thirsty
  plants, May to September). Tick marks are stored per ISO week, so the list resets every Monday.
- Ticking "Posadi X" also moves X to Posijano (unticking moves it back); the ticked task stays visible
  for the rest of the week.
- Step check marks on a plant page are saved with the plant when it is in Moj vrt, otherwise they
  last for the visit only.

## Smaller choices

- Confirmation after adding a plant: a toast with "Otvori moj vrt", 6 seconds.
- Offline notice: a small butter-coloured bar when the browser reports no network.
- Reminder: an `.ics` all-day event spanning the rest of the current window (or the next window),
  with a 9:00 alarm on its first day.
- Mobile onboarding shows the big intro only on the first step; later steps show a compact header.
- When onboarding is reopened from the header, the intro panel drops its logo (the header has one).
- **Testing other dates:** add `?datum=2027-03-15` to any URL. It sticks for the browser session;
  `?datum=` clears it.
